# Desk Sentry 桌面後照鏡

Desk Sentry 是 Windows 桌面後照鏡：在本機分析網路攝影機畫面，於有人從身後靠近時提供低干擾提醒與可選的閃避動作。

影像只在記憶體中處理，不錄影、不將畫面寫入磁碟，也不會傳到遠端服務。更新檢查預設關閉；只有使用者主動開啟或按下「立即檢查」時才會連線 GitHub。

## 功能

- 後方人物、移動與接近提醒，可分別開關小鏡子、邊緣閃光及提示音。
- 可調整大小的小鏡子模式、系統匣操作與全域快捷鍵。
- 低調模式以角落小點或上緣細線提示，並可指定顯示螢幕。
- 可選擇縮小指定程式、切到掩護視窗或蓋上黑幕；自動動作有確認時間與冷卻時間。
- 可依電腦鎖定狀態、監看時段或離座狀態自動暫停及執行動作。
- 最近提醒縮圖只存在記憶體；每日摘要只保存次數。
- 可選擇儲存臉部特徵以辨識熟悉的人；特徵由目前 Windows 帳號使用 DPAPI 加密。
- 可選擇記錄不含影像的數字診斷資料，協助分析誤報與漏報。

## 隱私承諾

Desk Sentry 的人物偵測與辨識都在本機執行。程式不儲存攝影機影像；最近提醒中的縮圖在程式結束後即消失。若啟用「認得的人」，程式只保存臉部特徵數值，不保存照片。

自動更新檢查預設關閉。開啟後，每 24 小時最多向 GitHub Releases 查詢一次；手動按「立即檢查」代表同意該次連線。查詢不會傳送設定、影像、臉部特徵或診斷資料，但 GitHub 仍可能取得一般網路連線資訊，例如來源 IP。

診斷功能由使用者選擇開啟，記錄框的位置、分數、狀態與效能數字；發生錯誤時也會記錄例外類型、訊息與去除絕對路徑的呼叫堆疊。分享診斷片段前，仍應自行檢查並移除可能辨識裝置或環境的資訊。

一般使用者不需要另外安裝 Git 或 Python。建議先使用免安裝版；發佈成品內含 python.org 官方 Windows 嵌入式 Python、程式原始碼與固定版本的相依套件，不使用 PyInstaller 或自製啟動器打包。

**選項一：免安裝版（建議）**

1. 從 Releases 下載 `DeskSentry-<版本>-portable.zip`。
2. 在 zip 檔上按右鍵選「解壓縮全部」，不要直接在壓縮檔內啟動。
3. 進入解壓後的 `DeskSentry` 資料夾，雙擊「啟動 Desk Sentry」。主視窗關閉後，圖示會留在工作列通知區；若沒看到，請按「^」顯示隱藏圖示。

請保留整個免安裝版資料夾。可攜版不會自行加入開機啟動，但仍使用 `%APPDATA%\DeskSentry` 保存設定，並與安裝版共用單一執行個體及使用者資料。若防毒軟體誤擋或隔離內附的 `pythonw.exe`，先確認檔案來自本專案 Releases 且雜湊符合 `SHA256SUMS.txt`；裝置政策允許時再從防毒隔離區還原，否則請重新下載並回報攔截畫面。

**選項二：安裝版**

1. 從 Releases 下載 `DeskSentry-<版本>-Setup.exe`。
2. 執行安裝程式；預設安裝到 `%LOCALAPPDATA%\Programs\DeskSentry`，不需要系統管理員權限。
3. 視需要保留或取消「開機時啟動」。之後也可在設定頁變更。

Inno Setup 安裝程式與專案程式碼目前尚未簽章；內附的 `python.exe`／`pythonw.exe` 則來自 python.org 官方嵌入式套件。若 SmartScreen 顯示警告，請先確認檔案來自本專案 Releases，並以 PowerShell 核對 SHA-256：

```powershell
Get-FileHash .\DeskSentry-<版本>-Setup.exe -Algorithm SHA256
```

結果應與同一版本的 `SHA256SUMS.txt` 相符。SHA-256 可發現檔案損壞或遭修改，但不等同程式碼簽章。若裝置政策禁止執行未簽章程式，請遵循裝置管理規範。

## 基本使用

1. 坐在平常位置並啟動 Desk Sentry，確認畫面中的自己已標示為「你」；若辨識錯誤，可直接點選預覽中的自己。
2. 關閉主視窗後，程式會留在系統匣監看。右鍵系統匣圖示可顯示、暫停或結束程式；暫停時會釋放攝影機。
3. 「小鏡子模式」會顯示可移動、可調整大小且永遠置頂的小視窗；雙擊可回到設定頁。
4. 最近提醒最多保留 30 張記憶體內縮圖。低調模式下縮圖預設遮蔽，點擊後暫時顯示。
5. 設定中的提醒、快捷鍵、自動動作與監看時段都可單獨調整。黑幕不是 Windows 鎖定畫面，可用快捷鍵、Esc 或雙擊關閉。

持續監看時，程式無法關閉攝影機的硬體指示燈。視角、距離、照明與攝影機效能都會影響提醒結果；使用者應在實際環境中調整靈敏度並確認行為。

## 升級與解除安裝

執行新版 installer 即可覆蓋升級。安裝程式會先要求執行中的程式正常結束，並保留設定與加密的臉部特徵。

可從 Windows「設定 → 應用程式 → 已安裝的應用程式」解除安裝。解除安裝會移除開機啟動項目，預設保留 `%APPDATA%\DeskSentry`；只有在提示時明確選擇刪除，才會一併移除設定、臉部特徵、數字診斷與每日摘要。

## 從原始碼執行

需要 Python 3.12。請在 PowerShell 執行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe tools\fetch_model.py
.\.venv\Scripts\python.exe -m desk_sentry
```

`fetch_model.py` 會下載三個固定版本的模型並核對 SHA-256；模型檔不納入版本控制。上一代 v1 原始碼已從公開工作樹移除。

開發與驗證方式見 [CONTRIBUTING.md](CONTRIBUTING.md)，發佈程序見 [RELEASING.md](RELEASING.md)，設計與資料流見 [DESIGN.md](DESIGN.md)。

## 疑難排解

### 開會時攝影機被佔用

攝影機模式預設為「自動」：先嘗試 Windows 共用唯讀後端，讓視訊會議同時使用相同攝影機；共用失敗時才嘗試獨占模式。若驅動不支援共用，可選「相容模式（獨占）」。

自動模式下，若開會期間共用失敗，程式不會改開獨占，會暫停監看到會議結束，結束後優先重試共用。

「開會時自動讓出攝影機」預設開啟。使用獨占後端時，程式每 2 秒在背景查看 Windows 的攝影機與麥克風使用紀錄；偵測到受支援的會議使用時會釋放攝影機，結束且使用紀錄連續清除 10 秒後才恢復。鎖定或非監看時段仍會維持暫停，共用後端成功時不會自動讓出。

相容模式會獨占攝影機；另一個 App 嘗試開啟但被 Windows 擋下時，可能完全不會留下攝影機使用紀錄。因此自動讓出主要依指定會議軟體的麥克風紀錄判斷：支援的封裝 App 名稱開頭為 `MSTeams_`、`MicrosoftTeams_`；支援的非封裝程式為 `ms-teams.exe`、`teams.exe`、`zoom.exe`、`cpthost.exe`、`webexmta.exe`、`ciscocollabhost.exe`、`atmgr.exe`、`lync.exe`、`skype.exe`、`slack.exe`。攝影機使用紀錄只有在其他 App 已先取得攝影機時才有幫助，例如在開會途中啟動 Desk Sentry。

瀏覽器不在麥克風白名單內，所以 Google Meet、Teams 網頁版，以及只開攝影機而未開麥克風的程式不會自動觸發讓出；請從系統匣選「暫時讓出攝影機」，結束後再選「恢復使用攝影機」。Windows 登錄紀錄也可能延遲；若會議軟體仍拿不到畫面，請使用相同的手動讓出操作。

Desk Sentry 會優先依已存裝置 ID、其次依名稱選擇攝影機。Windows 獨占開啟失敗後，若已存 ID 或名稱，只有目前 WinRT 的 VIDEO_CAPTURE 列舉（全部裝置，不只彩色攝影機）剛好一支，且其 ID（不分大小寫）或名稱符合已存資料時，才以 DirectShow index 0 作最後備援；列舉失敗、裝置不符或多於一支時不使用此備援。未存 ID 與名稱時，維持以設定索引嘗試 DirectShow。相容模式及自動模式的獨占退路都適用這項規則。限制是：只有 DirectShow 認得的虛擬攝影機仍可能占用 index 0。實際是否能同時使用取決於 Windows、驅動與另一個程式；維護者可執行 `python tools/camera_share_probe.py` 驗證，探測只輸出影格計數與狀態，不儲存影像。

### 「目前狀態」代表什麼？

- 「共用中，可與視訊會議同時使用」：Desk Sentry 正以共用模式取得畫面。
- 「相容模式：Teams、Zoom 等會議軟體開麥克風時自動讓出」：目前是獨占模式，指定的會議軟體使用麥克風時會自動釋放；若已關閉自動讓出，則顯示「相容模式：開會時需先暫停 Desk Sentry」。
- 「連線中…」：正在開啟或重新連接攝影機。
- 「已讓出給視訊會議，結束後自動恢復」：會議正在使用攝影機，Desk Sentry 會在會議結束後恢復。
- 「攝影機沒有回應，稍後自動重試」：攝影機操作逾時或斷線，程式會延遲後建立新的連線。
- 「已暫停」、「已暫停 · 電腦鎖定中」或「已暫停 · 非監看時段」：程式依手動、鎖定或排程原因暫停。
- 「無法確認已讓出攝影機；若會議軟體拿不到畫面，請結束 Desk Sentry」：釋放時發生錯誤，無法確認是否完成；結束程式可避免持續占用。

回報攝影機問題時，請按「目前狀態」旁的「複製診斷資訊」，貼上不含裝置名稱、路徑或使用者身分的版本、後端、格式與狀態摘要。

### 關閉更新檢查後，程式還會連網嗎？

不會。關閉自動更新且未按「立即檢查」時，應用程式不會主動發送網路請求。從原始碼執行的模型下載工具是開發者明確啟動的獨立操作。

### 程式會保存或上傳相機畫面嗎？

不會。攝影機影像與最近提醒縮圖只存在記憶體；診斷記錄也不含影像。

### 為什麼 Windows 顯示 SmartScreen 警告？

目前發佈成品尚未簽章。請只從本專案 Releases 下載並核對 `SHA256SUMS.txt`；受管理裝置應遵循組織政策。

### 為什麼沒有提醒？

請確認監看未暫停、攝影機可用，並檢查靈敏度、監看時段與警戒程度。遠處、靜止、尚在確認或使用者離座時的人影可能不會觸發完整提醒。

### 可以同時開啟安裝版與可攜版嗎？

不建議。兩者共用單一執行個體與使用者設定；重複啟動通常只會叫出既有視窗。
